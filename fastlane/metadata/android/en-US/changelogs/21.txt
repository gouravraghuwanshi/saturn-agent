Saturn 1.2.0. Many more Pi extensions now work on the phone. A new "works on Saturn" tab in Extensions lists the ones tested on a real phone (42 of the 43 most-used), and it updates on its own as more are tested. Extensions that need Linux programs, SQLite, image processing or a terminal (pi-lens, openwiki, browser-loop and others) now install and run; when part of an extension can't run on Android, the rest still installs instead of the whole install failing.
