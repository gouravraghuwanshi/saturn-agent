It works while you don't.

Every ask becomes its own task. Start three, lock the phone, go make tea. Saturn runs the commands, reads the errors, tries again and tells you when it's done.

  • A receipt when it's doneHow long it took, the steps it ran, and what it made or changed.
  • Things you keepLittle web apps, notes and reports land in Artifacts, ready to open or share.

It knows it's on a phone.

Saturn isn't a chat box. It has hands. Here's what you say, and what it quietly runs for you.

"Turn the torch off in ten minutes."

$ saturn-schedule in 10m -- termux-torch off

"What's draining my battery?"

$ termux-battery-status | jq .percentage

"Fix the failing test and open a PR."

$ npm test && git push && gh pr create

"Run this on my laptop instead."

$ ssh laptop 'make release'

"Summarise the PDF I just shared."

$ pdftotext lease.pdf - | head -200

"Check the router page and tell me who's online."

browser open http://192.168.1.1

Your stuff stays on your phone.

No accountThere's nothing to sign up for. Open the app and give it a model.

No server of oursSaturn talks to the AI provider you picked, and nobody else.

No trackingNo ads, no analytics. Your keys and files live in the app's private storage.

The one thing that leaves your phone is what the agent sends to your model so it can think. That's how every agent works, and we'd rather say it plainly. Read the privacy note.

How a phone runs a Linux agent.

Android won't run programs from an app's storage, but it will load native libraries shipped inside it. So Saturn ships node, bash and git as lib*.so files, links them into a tiny Linux-style folder when it starts, and runs the real Pi on top as its agent harness. No root, no Termux.
